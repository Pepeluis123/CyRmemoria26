🔢 Ensamblador, Sistemas de Numeración y Álgebra Booleana

Apuntes sobre la conversión entre sistemas Decimal, Binario, Octal y Hexadecimal, el uso indispensable del Lenguaje Ensamblador en informática moderna y los orígenes del álgebra de George Boole.

⚙️ Lenguaje Ensamblador

¿Pasar C++ a Ensamblador? Sí, el compilador traduce C++ a instrucciones ensamblador antes de generar el binario de máquina.

¿Alguien utiliza Ensamblador directamente? No para aplicaciones completas día a día, pero es indispensable en la informática moderna (firmware, controladores, sistemas embebidos, kernel de SO y optimización crítica).

Convertir sistema ensamblador-decimal:
11110010 (Binario) = 0xF2 (Hexadecimal)

Los programas deben intentar ocupar la mínima memoria posible. Los sistemas principales son: Decimal (Base 10), Binario (Base 2), Octal (Base 8) y Hexadecimal (Base 16).

🔌 Práctica Tinkercad: Sensor de Humedad en C++ (Arduino) Tinkercad + 5 LEDs

Conexión de sensor analógico de humedad del suelo en pin A1, control de excitación por pin A0 y escala visual con 5 LEDs (pines 8 a 12). 

// C++ code - Sensor de Humedad
int moisture = 0; // añade una variable que inicia con 0

void setup() {
  pinMode(A0, OUTPUT); // conecta el A0 como salida
  pinMode(A1, INPUT);  // el A1 como entrada
  Serial.begin(9600);  // conecta el monitor serial
  pinMode(8, OUTPUT);  // conecta los pines 8 a 12 como salida
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
  pinMode(11, OUTPUT);
  pinMode(12, OUTPUT);
}

void loop() {
  digitalWrite(A0, HIGH); // inicia con A0 encendido
  delay(10);              // esperamos 10 ms
  moisture = analogRead(A1); // la variable es lo que detecta A1
  digitalWrite(A0, LOW);  // el A0 se apaga
  Serial.println(moisture); // se comparte en monitor serial

  // Todos los leds empiezan apagados
  digitalWrite(8, LOW);
  digitalWrite(9, LOW);
  digitalWrite(10, LOW);
  digitalWrite(11, LOW);
  digitalWrite(12, LOW);

  if (moisture < 200) {
    digitalWrite(12, HIGH); // led 12 encendido
  } else if (moisture < 400) {
    digitalWrite(11, HIGH); // led 11 encendido
  } else if (moisture < 600) {
    digitalWrite(10, HIGH); // led 10 encendido
  } else if (moisture < 800) {
    digitalWrite(9, HIGH);  // led 9 encendido
  } else {
    digitalWrite(8, HIGH);  // led 8 encendido
  }
  delay(100);
}

🐞 Diagnóstico y Depuración de Errores

Aprende a identificar la diferencia entre errores de sintaxis, lógicos y de ejecución, y conoce los fallos habituales de 4º ESO.

⚠️ Fallo Típico 1: = vs ==

Confundir la asignación con la comparación es el error más común en 4º ESO.

❌ Incorrecto: if (x = 5)
✔️ Correcto: if (x == 5)

⚠️ Fallo Típico 2: input() en Python

input() siempre devuelve texto (str). Para sumar hay que convertirlo con int() o float().

❌ num = input("Edad: ")
✔️ num = int(input("Edad: "))
